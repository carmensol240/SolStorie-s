
# עדכון תיבות המידע בדף הבית

## סיכום השינויים

### 1. עדכון תוכן
- הסרת המילה "גם" מהתיבה הראשונה
- הטקסט החדש: "שימוש בטכנולוגיית NLP להתאמה אישית לילדים על הרצף התקשורתי"

### 2. הקטנת התיבות
- הקטנת ה-padding מ-`p-5` ל-`p-3`
- הקטנת גודל הטקסט בכותרת מ-`text-sm` ל-`text-xs`
- הקטנת גודל הטקסט בתיאור מ-`text-sm` ל-`text-xs`
- הקטנת גודל האייקון מ-`w-11 h-11` ל-`w-9 h-9`
- הקטנת הרווח בין האלמנטים מ-`gap-4` ל-`gap-3`

### 3. שיפור קישור מדיניות הפרטיות
- הגדלת גודל הטקסט מ-`text-xs` ל-`text-sm`
- הוספת רקע שקוף לשיפור הניגודיות
- הבלטת הקישור עם צבע בולט יותר

---

## פרטים טכניים

### קובץ: `src/components/home/GuestLanding.tsx`

**שינויים ב-FeatureCard:**
```text
padding:        p-5 → p-3
icon size:      w-11 h-11 → w-9 h-9
gap:            gap-4 → gap-3
title text:     text-sm → text-xs
subtitle text:  text-sm → text-xs
```

**שינוי בתוכן:**
```text
לפני: "שימוש בטכנולוגיית NLP להתאמה אישית גם לילדים..."
אחרי: "שימוש בטכנולוגיית NLP להתאמה אישית לילדים..."
```

**שיפור קישור הפרטיות:**
```text
text size:      text-xs → text-sm
background:     הוספת רקע שקוף עם טשטוש
link color:     text-purple-700 → text-purple-800
```
