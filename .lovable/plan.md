**Edge Function חדש: `supabase/functions/elevenlabs-tts/index.ts`**

```text
- יקבל טקסט וישלח ל-ElevenLabs API
- יחזיר audio/mpeg לנגינה בצד הלקוח
- ישתמש בקול עברי (או קול מתאים לילדים)
- ידרוש ELEVENLABS_API_KEY כ-secret
```

```text

- isLoading: boolean - האם טוען audio
```

## פרטים טכניים

### Edge Function: elevenlabs-tts

```typescript
// supabase/functions/elevenlabs-tts/index.ts
serve(async (req) => {
  const { text, voiceId = "JBFqnCBsd6RMkjVDRZzb" } = await req.json();
  
  const response = await fetch(
    `https://api.elevenlabs.io/v1/text-to-speech/${voiceId}`,
    {
      method: "POST",
      headers: {
        "xi-api-key": ELEVENLABS_API_KEY,
        "Content-Type": "application/json",
      },
      body: JSON.stringify({
        text,
        model_id: "eleven_multilingual_v2",
        voice_settings: {
          stability: 0.6,
          similarity_boost: 0.8,
        },
      }),
    }
  );
  
  return new Response(response.body, {
    headers: { "Content-Type": "audio/mpeg" },
  });
});
```
