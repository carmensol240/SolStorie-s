
# 🎁 תוכנית: סיפור ראשון במתנה למשתמשים חדשים

## סיכום המצב הקיים

### ✅ מה כבר עובד
- **טריגר במסד הנתונים**: הפונקציה `handle_new_user` יוצרת פרופיל עם `story_credits = 1` לכל משתמש חדש
- **ערך ברירת מחדל**: העמודה `story_credits` מוגדרת עם 1 כברירת מחדל
- **תצוגת קרדיטים**: המערכת מציגה את מספר הקרדיטים במסך הבית

### ⚠️ מה חסר
1. **הודעת ברכה עם הדגשת המתנה**: ההודעות הקיימות לא מזכירות את הסיפור החינמי כמתנה
2. **אימות בצד השרת**: אין בדיקה אם משתמש חדש קיבל את קרדיט הפתיחה במקרה של תקלה

- לאחר אישור תנאי שימוש

## שלב 2: באנר "סיפור ראשון במתנה" במסך הבית

### רכיב חדש: `WelcomeGiftBanner.tsx`

נציג באנר צבעוני למשתמשים חדשים (שיש להם בדיוק 1 קרדיט ו-0 סיפורים):

```text
🎁 יש לך סיפור ראשון במתנה!
לחצו כאן להתחיל להרפתקה
[כפתור: צור סיפור חדש]
```

**מיקום**: מעל ה-CTA הראשי ב-`LoggedInHome.tsx`

**תנאי הצגה**: 
- `credits === 1`
- `storyCount === 0`

הבאנר ייעלם אוטומטית לאחר שהמשתמש יוצר את הסיפור הראשון.

---

## שלב 3: אימות בצד השרת

### עדכון Edge Function: `generate-story/index.ts`

נוסיף בדיקת בטיחות לפני סירוב על בסיס קרדיטים:

```text
לוגיקה:
1. בדוק אם למשתמש יש story_credits >= 1
2. אם הקרדיטים = 0, בדוק:
   - האם יש לו סיפורים קיימים? (סופר stories WHERE user_id = X)
   - אם אין סיפורים כלל = משתמש חדש שלא קיבל קרדיט פתיחה
   - במקרה זה: תקן את הפרופיל ל-1 קרדיט והמשך
3. רק אם יש סיפורים קודמים AND קרדיטים = 0 → החזר שגיאת "אין קרדיטים"
```

### פסאודו-קוד:
```
אם credits = 0:
  story_count = COUNT(*) FROM stories WHERE user_id = current_user
  
  אם story_count = 0:
    // משתמש חדש ללא סיפורים - תיקון אוטומטי
    UPDATE profiles SET story_credits = 1 WHERE id = current_user
    המשך ליצירת סיפור
  אחרת:
    // משתמש עם היסטוריה שנגמרו לו הקרדיטים
    החזר שגיאה: "נגמרו הקרדיטים"
```

## פרטים טכניים

### באנר המתנה (WelcomeGiftBanner)

```text
סטייל:
- רקע גרדיאנט סגול-ורוד-כתום
- אייקון מתנה 🎁 מונפש
- טקסט: "יש לך סיפור ראשון במתנה!"
- כפתור CTA ראשי
- פינות מעוגלות עם צל
```

### בדיקת הזכאות

הבאנר יוצג רק כאשר:
```typescript
const showWelcomeGift = credits === 1 && storyCount === 0;
```

נצטרך לשלוף את מספר הסיפורים מ-Supabase ב-`LoggedInHome`.

## תוצאה צפויה

1. ✅ משתמש חדש נרשם → מקבל הודעה על מתנה
2. ✅ במסך הבית רואה באנר צבעוני "סיפור במתנה"
3. ✅ מספר הקרדיטים מציג "1" מיד אחרי הרשמה
4. ✅ אם יש תקלה והקרדיט לא נוצר → השרת מתקן אוטומטית
5. ✅ הבאנר נעלם אחרי יצירת הסיפור הראשון
