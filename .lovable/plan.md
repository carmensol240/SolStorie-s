

# בדיקת איכות תמונה אוטומטית במסך "ספרו לנו על הילד/ה"

## מה ישתנה
כשמשתמש מעלה תמונה, המערכת תנתח אותה אוטומטית באמצעות AI ותציג ליד כל קריטריון סימון V (עומד בדרישה) או X (לא עומד בדרישה).

## איך זה יעבוד

1. המשתמש מעלה תמונה
2. התמונה נשלחת לפונקציית backend שמנתחת אותה באמצעות Gemini Vision
3. התוצאות מוצגות כרשימת קריטריונים עם V/X ליד התמונה שהועלתה

## שינויים טכניים

### 1. פונקציית backend חדשה: `validate-child-photo`
- מקבלת תמונה בפורמט base64
- שולחת ל-Gemini 2.5 Flash (מודל מהיר שתומך בתמונות, ללא צורך ב-API key)
- מחזירה אובייקט JSON עם תוצאות לכל קריטריון:
  - `facingForward` (פנים קדימה)
  - `singlePerson` (דמות יחידה)
  - `noAccessories` (ללא אביזרים)
  - `goodLighting` (תאורה טובה)

### 2. עדכון `ChildInfoStep.tsx`
- הוספת state חדש: `photoValidation` לשמירת תוצאות הבדיקה
- לאחר העלאת תמונה, קריאה לפונקציית ה-backend
- הצגת רשימת הקריטריונים מתחת לתמונה שהועלתה עם V/X דינמי לפי תוצאות הבדיקה
- הצגת spinner קטן בזמן הבדיקה

### 3. מבנה התצוגה לאחר העלאת תמונה
```
[תמונה/אווטאר]
V פנים מסתכלות קדימה
V דמות יחידה בתמונה  
X ללא אביזרים (משקפי שמש, כובע)
V תאורה טובה וברורה
[כפתורי פעולה: צור אווטאר / מחק]
```
