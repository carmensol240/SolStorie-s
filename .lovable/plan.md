
# עדכון טקסט ועיצוב תיבות הפיצ'רים

## סיכום השינויים

### 1. עדכון תוכן התיבה הראשונה
הטקסט החדש לתיבה הראשונה:
- **כותרת**: "התאמה אישית חכמה"
- **תיאור**: "סיפורים שנבנים עבור ילדכם, עם התאמה רגישה גם לרצף התקשורתי."

### 2. התאמת גודל הטקסט ב-Description
- שינוי גודל הפונט מ-`text-xs` ל-`fontSize: '0.9rem'` באמצעות inline style
- שינוי ה-line-height ל-`1.2` לטקסט צפוף יותר

### 3. שמירה על אפקט הזכוכית
אפקט הזכוכית הקיים יישמר:
- `background: rgba(255, 255, 255, 0.6)`
- `backdrop-filter: blur(10px)`
- גבול לבן עדין ו-box-shadow

### 4. אימות - ללא כפתורים מיותרים
הקובץ הנוכחי לא מכיל כפתור "הקראה" או אייקוני נגישות בתיבות הפיצ'רים - מאושר.

## פרטים טכניים

### קובץ: `src/components/home/GuestLanding.tsx`

```tsx
// לפני
<p className="text-xs font-medium text-purple-600 leading-relaxed">
  {subtitle}
</p>

// אחרי
<p 
  className="font-medium text-purple-600"
  style={{ fontSize: '0.9rem', lineHeight: '1.2' }}
>
  {subtitle}
</p>
```

## תוצאה צפויה
- התיבה הראשונה תציג את הטקסט החדש והמשודרג
- טקסט התיאור יהיה קריא אך צפוף יותר (line-height: 1.2)
- גודל הפונט (0.9rem) יבטיח שהתיבות לא יחפפו את תמונת הילדים העפים
- אפקט הזכוכית יישמר
