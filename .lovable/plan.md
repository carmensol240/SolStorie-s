## שימוש במערכת הקופונים

### יצירת קופון (דרך SQL)
```sql
-- קופון הנחה 15%
INSERT INTO coupons (code, coupon_type, discount_percent, max_uses)
VALUES ('SAVE15', 'discount', 15, 100);

-- קופון 5 סיפורים חינם
INSERT INTO coupons (code, coupon_type, free_stories, max_uses)
VALUES ('FREE5', 'extra_stories', 5, 50);
```

### הגבלת הורדות PDF
- משתמשים חינמיים: 3 הורדות לחודש
- מנויים (credits > 1): ללא הגבלה
- Hook: `usePdfDownloadLimit`
