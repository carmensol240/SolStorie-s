# העברת שדות לבוש למסך 1

## מה משתנה

בקובץ `src/components/wizard/ChildInfoStep.tsx`:

- מעבירים את בלוק "סוג לבוש" ואת בלוק "צבע עיקרי" (שורות ~787–830) ממסך 2 (`screen === 2`) למסך 1 (`screen === 1`).
- במסך 1, הבלוקים יוצבו **בסוף** — אחרי שדה השפה (בסוף הבלוק של `screen === 1`).

## מה נשאר ללא שינוי

- תוכן/לוגיקת השדות עצמם (האופציות, `updateFormData`, הסטיילינג) — זהה לחלוטין.
- `canProceedStep1` ו-`canProceedPersonalization` — לא משתנים; לבוש נשאר אופציונלי.
- שדות שיער, תסרוקת, שם כיתה/גן, תמונה ואישור — נשארים במסך 2 כמו היום.
- קבצים אחרים — לא נגעים.

## מבנה מסך 1 לאחר השינוי

```text
1. ברכה (מחוברים)
2. כותרת
3. שורת פרופילים שמורים
4. שם + פרטים קבועים
5. מגדר
6. גיל + שפה
7. סוג לבוש (חדש)
8. צבע לבוש (חדש)
```

## מבנה מסך 2 לאחר השינוי

```text
1. כותרת
2. צבע שיער + תסרוקת
3. שם כיתה/גן (אנשי חינוך)
4. אזור העלאת תמונה + אישור
5. שמירת פרופיל
```

## בדיקת אימות

הרצה של `bunx tsgo --noEmit` לאחר העריכה.
