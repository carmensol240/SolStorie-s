יצירת טבלה חדשה `pdf_downloads`:

```sql
CREATE TABLE public.pdf_downloads (
  id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id uuid NOT NULL REFERENCES auth.users(id),
  story_id uuid NOT NULL,
  downloaded_at timestamptz DEFAULT now()
);

-- RLS: משתמשים רואים רק את ההורדות שלהם
CREATE POLICY "Users can view own downloads"
  ON pdf_downloads FOR SELECT
  USING (auth.uid() = user_id);
  
CREATE POLICY "Users can insert own downloads"
  ON pdf_downloads FOR INSERT
  WITH CHECK (auth.uid() = user_id);
```

## שלב 3: מערכת קופונים

### 3.1 יצירת טבלת קופונים בבסיס הנתונים

```sql
CREATE TABLE public.coupons (
  id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  code text UNIQUE NOT NULL,
  coupon_type text NOT NULL CHECK (coupon_type IN ('discount', 'extra_stories')),
  -- For discount coupons
  discount_percent integer CHECK (discount_percent IN (10, 15)),
  -- For extra stories coupons
  free_stories integer,
  -- Validity
  max_uses integer DEFAULT NULL, -- NULL = unlimited
  current_uses integer DEFAULT 0,
  expires_at timestamptz DEFAULT NULL, -- NULL = no expiry
  is_active boolean DEFAULT true,
  created_at timestamptz DEFAULT now()
);

-- Track coupon redemptions
CREATE TABLE public.coupon_redemptions (
  id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  coupon_id uuid REFERENCES public.coupons(id),
  user_id uuid NOT NULL,
  redeemed_at timestamptz DEFAULT now(),
  UNIQUE(coupon_id, user_id) -- Each user can use a coupon once
);
```

## פרטים טכניים

### לוגיקת בדיקת הורדות PDF

```typescript
const checkDownloadLimit = async (userId: string): Promise<boolean> => {
  const startOfMonth = new Date();
  startOfMonth.setDate(1);
  startOfMonth.setHours(0, 0, 0, 0);
  
  const { count } = await supabase
    .from('pdf_downloads')
    .select('*', { count: 'exact', head: true })
    .eq('user_id', userId)
    .gte('downloaded_at', startOfMonth.toISOString());
  
  return (count || 0) < 3;
};
```

### אימות קופון

```typescript
const validateCoupon = async (code: string) => {
  const { data: coupon } = await supabase
    .from('coupons')
    .select('*')
    .eq('code', code.toUpperCase())
    .eq('is_active', true)
    .single();
  
  if (!coupon) return { valid: false, message: 'קוד לא תקף' };
  if (coupon.expires_at && new Date(coupon.expires_at) < new Date()) 
    return { valid: false, message: 'הקופון פג תוקף' };
  if (coupon.max_uses && coupon.current_uses >= coupon.max_uses)
    return { valid: false, message: 'הקופון מוצה' };
  
  return { valid: true, coupon };
};
```
