## 1. החלפת מנוע TTS לAzure Speech Services

### 1.1 Edge Function חדש: azure-speech-tts

**קובץ: `supabase/functions/azure-speech-tts/index.ts`**

```text
מפרט:
- שימוש ב-Azure Cognitive Services Speech SDK
- קול: he-IL-HilaNeural (קול עברי נשי)
- מהירות דיבור: rate="0.9" (לאווירת סיפורי לילה)
```

- `AZURE_SPEECH_KEY` - מפתח API מAzure Portal
- `AZURE_SPEECH_REGION` - אזור (לדוג' `westeurope`)

### 1.2 עדכון config.toml

```toml
[functions.azure-speech-tts]
verify_jwt = false
```

### 1.3 Hook עדכון: use-text-to-speech.ts


```typescript
// Pre-fetch הבאה כשמציגים עמוד
```

## פרטים טכניים

### Edge Function: azure-speech-tts

```typescript
const corsHeaders = {
  'Access-Control-Allow-Origin': '*',
  'Access-Control-Allow-Headers': 'authorization, x-client-info, apikey, content-type, ...',
};

serve(async (req) => {
  if (req.method === 'OPTIONS') {
    return new Response(null, { headers: corsHeaders });
  }

  const { text } = await req.json();
  const AZURE_SPEECH_KEY = Deno.env.get('AZURE_SPEECH_KEY');
  const AZURE_SPEECH_REGION = Deno.env.get('AZURE_SPEECH_REGION');
  
  // Build SSML for Hebrew voice with 0.9x rate
  const ssml = `
    <speak version="1.0" xmlns="http://www.w3.org/2001/10/synthesis" xml:lang="he-IL">
      <voice name="he-IL-HilaNeural">
        <prosody rate="0.9">
          ${text}
        </prosody>
      </voice>
    </speak>
  `;
  
  const response = await fetch(
    `https://${AZURE_SPEECH_REGION}.tts.speech.microsoft.com/cognitiveservices/v1`,
    {
      method: 'POST',
      headers: {
        'Ocp-Apim-Subscription-Key': AZURE_SPEECH_KEY,
        'Content-Type': 'application/ssml+xml',
        'X-Microsoft-OutputFormat': 'audio-16khz-128kbitrate-mono-mp3',
      },
      body: ssml,
    }
  );
  
  return new Response(response.body, {
    headers: { ...corsHeaders, 'Content-Type': 'audio/mpeg' },
  });
});
```

### Pre-fetch Images

```typescript
// בתוך StoryViewer.tsx
const prefetchNextImage = useCallback((pageIndex: number) => {
  if (!story || pageIndex >= story.pages.length - 1) return;
  
  const nextPage = story.pages[pageIndex + 1];
  if (nextPage?.illustration_url) {
    const img = new Image();
    // Use signed URL if available
    const signedUrl = getSignedUrl(nextPage.illustration_url);
    img.src = signedUrl || nextPage.illustration_url;
  }
}, [story, getSignedUrl]);

useEffect(() => {
  prefetchNextImage(currentPage);
}, [currentPage, prefetchNextImage]);
```
