

# תיקון קולקטיבי - עיצוב תצוגת סיפורים כספר פתוח

## בעיות שזוהו

1. **סיפור נפתח מדף 2**: הלוגיקה הנוכחית מקבצת 2 דפים לכל "פריסה" (spread), מה שגורם לדילוג על דף ראשון או הצגת טקסט כפול
2. **טקסט חתוך ומילים חסרות**: קיבוץ 2 טקסטים בעמוד ימני אחד גורם לגלישת תוכן
3. **אין סדר בעמודים**: הפריסה הנוכחית מקבצת עמודים בזוגות (0+1, 2+3...) במקום להציג כל עמוד בנפרד

## הפתרון - ספר פתוח 1:1

כל "פריסה" תציג עמוד אחד בלבד:
- **צד ימין (RTL)**: טקסט העמוד - עם גלילה אם הטקסט ארוך
- **צד שמאל**: איור העמוד
- **דפדוף**: כפתורי חיצים בלבד, עמוד אחד בכל פעם

```text
+---------------------------+---------------------------+
|                           |                           |
|       [איור העמוד]        |      [טקסט העמוד]         |
|                           |                           |
|       צד שמאל             |       צד ימין (RTL)       |
|                           |                           |
+---------------------------+---------------------------+
              < חץ הבא     עמוד X/Y     חץ קודם >
```

## מבנה ניווט חדש

- **עמוד -1**: עטיפה (כותרת + איור דף 1)
- **עמוד 0 עד N-1**: כל עמוד סיפור בנפרד (איור שמאל, טקסט ימין)
- **עמוד N**: סיום (משוב + כפתורי ניווט)

## פרטים טכניים

### קובץ: `src/pages/StoryViewer.tsx`

**שינויים עיקריים:**

1. **הסרת לוגיקת spreads** (שורות 815-833): במקום קיבוץ לזוגות, כל עמוד מוצג בנפרד
   - הסרת המשתנה `spreads` ולולאת הקיבוץ `for (i += 2)`
   - `currentPage` ינוע מ-`-1` (עטיפה) דרך `0` עד `pages.length - 1` (עמודי סיפור) ועד `pages.length` (סיום)
   - `isEndPage` = `currentPage >= story.pages.length`

2. **פישוט הניווט** (שורות 836-860): 
   - `handleSpreadChange` יהפוך ל-`handlePageNav` פשוט שמזיז עמוד אחד בכל פעם
   - מקסימום = `story.pages.length` (עמוד סיום)
   - מינימום = `-1` (עטיפה)

3. **רינדור עמוד סיפור** (שורות 1106-1234):
   - במקום `currentSpread.pages.map(...)` עם 2 טקסטים - הצגת `story.pages[currentPage]` בודד
   - צד ימין: טקסט אחד בלבד עם `overflow-y: auto`
   - צד שמאל: איור אחד בלבד
   - חיצי ניווט בצידי העמוד + תחתית

4. **עדכון dot indicator** (שורות 1238-1247):
   - נקודה לכל עמוד במקום לכל spread
   - לסיפורים ארוכים (מעל 8 עמודים) - הצגת מספר עמוד בלבד במקום נקודות

5. **עדכון keyboard navigation** (שורות 448-460):
   - יפנה ל-`handlePageNav` במקום `handlePageChange`

### קובץ: `src/pages/StoryViewer.css`

- תיקון `open-book-page-right` עם `padding-top: 12px` ו-`overflow-y: auto` למניעת חיתוך
- הוספת `min-height: 0` ל-flex containers למניעת גלישה

### לא ישתנו

- עטיפת הסיפור (cover page) - נשארת כמו שהיא
- עמוד הסיום (end page) - נשאר כמו שהוא
- כל הפיצ'רים (ניקוד, עריכה, TTS, שיתוף, PDF) - נשארים פעילים
- עיצוב הספר הפתוח (צבעים, צללים, קיפולי פינות) - נשאר כמו שהוא
