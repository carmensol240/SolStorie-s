## תיקון פלטת צבעים נחתכת בדסקטופ – Online Coloring Canvas

### הבעיה
בקובץ `src/components/story/OnlineColoringCanvas.tsx`:
- ב-`md+` כפתורי הצבע גדלים ל-`w-14 h-14` (56px), והפלטה מורכבת מ-3 שורות (כלים + skin/earth + צבעים). גובה כולל בפועל כ-170-200px.
- `resizeCanvases` שומר רק `toolbarHeight = 100` בכל הגדלים.
- המעטפת היא `h-100dvh` עם `overflow-hidden`, כך שכשהפלטה גבוהה מהשטח השמור היא נחתכת בתחתית.

### השינוי
קובץ יחיד: `src/components/story/OnlineColoringCanvas.tsx`

1. **התאמת גובה התפריט שמורד מגובה הקנבס** ב-`resizeCanvases`:
   - במקום `const toolbarHeight = isMobile ? 100 : 100;` להשתמש בערך גבוה יותר לדסקטופ כדי לשמור מקום אמיתי לפלטה: `isMobile ? 110 : 200` (top bar ~48 + bottom toolbar ~150 בדסקטופ).

2. **הקטנה קלה של כפתורי הצבעים בדסקטופ** כדי שהפלטה תיכנס בנוחות גם במסכי לפטופ נמוכים (768-800 px גובה):
   - בשתי שורות הצבעים: `md:w-14 md:h-14` → `md:w-11 md:h-11`.

לא נוגעים בלוגיקת ציור, פליאט, היסטוריה, או כל UI אחר.

### בדיקה
- בדסקטופ (1366×768 ו-1280×800): כל שלוש שורות הפלטה נראות במלואן, הקנבס מתאים את עצמו לשטח הזמין.
- במובייל: ללא רגרסיה (השינוי במידות חל רק ב-`md+`).
