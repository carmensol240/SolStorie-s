# סנכרון תמונת פרופיל לטאב נבחר בספרייה

## מטרה
לסנכרן בין התמונה העגולה של הילד/ה בכותרת מסך הספרייה לטאב המסונן שנבחר. כיום התמונה נשארת קבועה על הילד/ה האחרון/ה שנבחר/ה בזרימה אחרת, ולא מתחלפת כשמשנים טאב.

## שינויים מתוכננים
בקובץ `src/pages/Library.tsx` בלבד:

1. **ייבוא `setUserData`** — להוסיף את `setUserData` מהמודול `@/lib/user-storage` (כיום מיובא רק `getUserData`).

2. **state חדש לטאב פעיל** — להוסיף:
   ```ts
   const [activeTabValue, setActiveTabValue] = useState<string>('__all');
   ```

3. **הפיכת ה־Tabs לבקר** — ברכיב הטאבים של הילדים/הסיפורים (בערך שורה 835), להוסיף:
   ```tsx
   value={activeTabValue}
   onValueChange={(value) => {
     setActiveTabValue(value);
     if (user && value !== '__all' && value !== '__other') {
       setUserData(user.id, 'selected_child_id', value);
     }
   }}
   ```
   ההגבלה לערכים שאינם `__all`/`__other` מבטיחה שלא נדרוס את `selected_child_id` כשבוחרים בקטגוריה כללית או אחר.

4. **קביעת הילד/ה שמוצג/ת בכותרת** — להחליף את הלוגיקה הנוכחית של `selectedChildId` בלוגיקה שמתחשבת בטאב הפעיל:
   - אם נבחר טאב ספציפי של ילד/ה — להשתמש ב־`id` של אותו/ה ילד/ה.
   - אם נבחר `__all` או `__other` — לשמור על הילד/ה האחרון/ה שנבחר/ה (מהלוקל סטורג' או מהטאב הקודם).
   - אם עדיין אין ילד/ה נבחר/ה — לחזור לילד/ה הראשון/ה ברשימת `children`.

5. **שמירה על `useChildAvatar` כמו שהוא** — `useChildAvatar(selectedChildName)` ימשיך לעבוד כרגיל, ורק `selectedChildName` יחושב מחדש לפי הילד/ה הנבחר/ת בטאב.

## דברים שלא נוגעים בהם
- לוגיקת `childTabs` וסינון הסיפורים.
- ההוק `useChildAvatar` או מקור `avatarUrl`.
- קבצים אחרים מלבד `src/pages/Library.tsx`.

## איך נבדוק
- נכנס למסך הספרייה עם משתמש שיש לו יותר מילד/ה אחד/ת ולכל אחד/ת אוatar שונה.
- נבדוק שבעת החלפת טאב לילד/ה אחר/ת, התמונה העגולה בכותרת משתנה בהתאם.
- נבדוק שבחזרה לטאב "הכל" התמונה נשארת על הילד/ה האחרון/ה שנבחר/ה.
- נבדוק שאין שגיאות TypeScript לאחר השינוי.
