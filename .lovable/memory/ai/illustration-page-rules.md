---
name: Illustration page rules
description: Hero once, no text, parent clothes always, never copy page 1 composition
type: constraint
---
- Hero child appears once per picture: no duplicates, twins or lookalike child. Named companions (siblings, friends, the regular cast Sol/Ben/Mia/Zoe/Leo) are allowed and must appear when the page includes them.
- No text, letters, captions or signs drawn in any picture (only exception: the learning letter/number in letter/number stories).
- Parent-chosen clothing type and colour win on every page and topic; superhero costume/cape only if the parent chose "superhero".
- Later pages keep the same child but use a new pose, angle and background; never copy page 1's composition.
